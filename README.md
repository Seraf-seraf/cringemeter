# Кринжометр

Telegram-бот для оценки видео: Кринж / Некринж, общие голоса и топ.

Бот предназначен для одной группы. По согласованному контракту видео и
видеокружки получают кнопки **«🤡Кринж»** и **«Некринж🙂‍↕️»**. Повторные
публикации одного `file_unique_id` используют общие голоса: один текущий выбор
пользователя на файл. `/top` показывает до 10 уникальных медиа с минимум
5 голосами. Бинарные видео и `file_id` не сохраняются.

Стек: Go, Telegram Bot API через webhook, Vercel Go Functions, Turso (libSQL).

Сейчас реализованы каркас и HTTP-контракт `/api/webhook`: POST, проверка secret,
ограничение тела, проверка целевой группы и фильтрация собственных сообщений.
Операции Telegram и БД будут добавлены на следующих этапах.

Для проверки требуется Go 1.22 или новее:

```sh
make test
make vet
```

Структура: `api/` — HTTP entry points; `internal/domain/` — бизнес-правила;
`internal/app/` — сценарии; `internal/adapters/` — внешние интеграции.

В `.env.example` перечислены будущие настройки. Первые пять переменных
обязательны; `TOP_LIMIT` и `TOP_MIN_VOTES` имеют значения по умолчанию 10 и 5.
`TELEGRAM_WEBHOOK_SECRET` должен содержать от 1 до 256 символов `A-Z`, `a-z`,
`0-9`, `_`, `-`. Настройки проверяются при вызове handler; `.env` автоматически
не загружается. Не сохраняйте настоящие токены в Git, логах или документации.

Перед каждым этапом обязательны актуальные
[канонические инструкции](https://github.com/Seraf-seraf/AGENTS.md/blob/main/AGENTS.md)
